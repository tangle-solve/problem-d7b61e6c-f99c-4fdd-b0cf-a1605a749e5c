### ALGO-000248: Sustainable staffing and funding for independent cloud-algorithm evaluation
- **Subfield:** Experimental algorithms, benchmarks, infrastructure, and funding
- **Open:** Establish a funded, independently operated cloud-evaluation track with public cost accounting, reproducible environments, archived artifacts, and staffing sufficient for repeated annual operation.
